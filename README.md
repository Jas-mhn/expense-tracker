# Expense Tracker

A simple console application built in Python to record, view, and analyze daily expenses.

## Features
- Add expenses with date, category, amount, and a short note
- Input validation for invalid amounts
- View all expenses in a formatted table
- View total spending and category-wise summary
- Data saved permanently in a JSON file

## Technologies Used
- Python 3
- JSON (file storage)

## How to Run
1. Make sure Python 3 is installed.
2. Download `expense_tracker.py`.
3. Open a terminal in the folder and run:
```
   python expense_tracker.py
```
4. Choose an option from the menu.
